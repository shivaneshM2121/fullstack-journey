# Full Stack Journey — Notes

## How to use this file

After EVERY study session, add an entry below. Takes 5 minutes. Don't skip it.
Write in YOUR words, not copy-paste from tutorials. If you can't explain it simply, you don't understand it yet.

---

## Template (copy this for each session)

```
### Date: [Day, Date]
**Week:** [X] | **EMC Section:** [X.X]
**Hours studied:** [X]

**What I learned today:**
- [1-3 sentences in your OWN words. Explain it like you're teaching a friend.]

**What confused me:**
- [Be specific. Not "CSS is hard." Instead: "I don't understand why margin: auto centers horizontally but not vertically."]

**What I built / coded:**
- [What did you actually type and run? Link to file or describe it.]

**Errors I faced:**
- [Paste the exact error + how you fixed it. This is GOLD for future you.]

**Key code snippet I want to remember:**
- [One small piece of code that clicked today.]
```

## Example Entry (this is what a GOOD entry looks like)

### Date: Sunday, May 10, 2026

**Week:** 1 | **EMC Section:** 1.1–2.3
**Hours studied:** 2.5

**What I learned today:**

- The internet is basically computers talking to each other using HTTP. A URL is just an address that tells the browser which computer to talk to and what page to ask for. Frontend is what users see (HTML/CSS/JS), backend is the logic and database behind it.
- HTML tags come in pairs like <h1></h1>. Some are self-closing like <img>. Every page needs <!DOCTYPE html>, <html>, <head>, and <body>.

**What confused me:**

- What's the difference between <div> and <section>? Both seem to just group things. Asked mentor — div is generic, section is semantic (tells the browser this is a meaningful section). Use section when the content has a heading.

**What I built / coded:**

- Built about-me.html with my name, a short bio, a photo, and 3 links to my social profiles. Opened it in Chrome. Looked ugly but it WORKED.

**Errors I faced:**

- Image didn't show up. Error: "Failed to load resource." Fix: I wrote `src="photo.jpg"` but the file was actually named `Photo.JPG`. File names are case-sensitive! Changed it and it worked.
- Forgot closing </p> tag. The whole paragraph merged with the next one. Learned that unclosed tags mess up everything below them.

**Key code snippet I want to remember:**

```html
<!-- Basic HTML page structure -->
<!DOCTYPE html>
<html>
  <head>
    <title>My Page</title>
  </head>
  <body>
    <h1>Hello World</h1>
    <p>This is my first page.</p>
  </body>
</html>
```

## Why this matters (read this once, then forget it)

1. **"What I learned" forces you to process.** Writing it in your own words moves it from short-term to long-term memory. If you can't write it, you didn't learn it.

2. **"What confused me" is your revision list.** Before each new session, read last week's confusions. Half of them will click on their own. The rest — ask me.

3. **"Errors I faced" is your secret weapon.** In 3 months you'll hit the SAME error again and forget the fix. Future-you will thank past-you for writing it down. Professional developers keep error logs too — this is a real industry habit.

4. **"Key code snippet" builds your personal cheatsheet.** By month 8, you'll have 35+ snippets you wrote yourself. Better than any cheatsheet online because it's in YOUR context.
